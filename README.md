# WebCraft Club

Учебный веб-сайт клуба веб-разработки. Проект создан для практики верстки на HTML и CSS, работы с системой контроля версий Git, ветвления, Pull Request и публикации через GitHub Pages.

## Как открыть сайт локально
1. Скачайте или клонируйте репозиторий на компьютер.
2. Откройте файл `index.html` в любом браузере (или запустите через Live Server в VS Code).
