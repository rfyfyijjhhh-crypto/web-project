# ТехноСтарт — сайт клуба программирования и робототехники

Учебный статический веб-сайт с описанием направлений клуба, расписанием занятий и навигацией между страницами.

## Страницы и возможности
- `index.html` — главная страница с введением, основными направлениями и информацией о занятиях.
- `courses.html` — страница с учебными модулями, описанием итогового результата и возвратом на главную.

## Использованные технологии
- HTML5
- CSS3 (Flexbox, CSS Grid, медиазапросы)
- Git и GitHub (ветки, Pull Request, GitHub Pages)

## Локальный запуск
1. Склонируйте репозиторий или скачайте архив проекта.
2. Откройте файл `index.html` в любом современном браузере.
