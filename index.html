Чему мы учимся

Постепенно переходим от базовой разметки к адаптивной вёрстке и командной работе.

HTML и семантика

Строим понятную структуру страниц: заголовки, списки, навигацию, формы и доступность контента.

CSS и адаптивность

Настраиваем типографику, сетки Flexbox и Grid, а также медиазапросы для удобного просмотра на телефонах и ПК.

Git и GitHub

Ведём историю изменений через коммиты, работаем в ветках, оформляем Pull Request и публикуем сайты через GitHub Pages.
